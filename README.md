# Air Sense

AirSense is an IoT-based device designed to monitor and detect harmful gases in the atmosphere, such as Ammonia (NH3), Carbon Dioxide (CO2), Carbon Monoxide (CO), Alcohol vapors, Benzene, Nitrogen Oxides (NOx), and Toluene. It provides real-time air quality monitoring, categorizes gas levels, and triggers alerts when dangerous levels are detected.

## How It Works

1. Sensing: The IoT device detects gases using advanced sensors.

2. Processing: Sensor data is processed and categorized into Low, Normal, or High.

3. Alerting: A red LED and buzzer activate when gas levels are high.

4. Communication: The Flask API processes data and sends it to the mobile app for real-time monitoring.

5. Control: The mobile app allows users to control the system, view data, and access logs.
